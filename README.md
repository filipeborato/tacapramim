# tacapramim

A simple JUCE-based VST3 audio file player plugin, useful for auditioning audio
files inside the JUCE Plugin Host (or any DAW) during DSP development and
testing. Browse the file tree, drop a file on the waveform, and play it back
with gain and pan control.

![playVstAudio](https://user-images.githubusercontent.com/21025394/236606022-7219d99b-f504-4626-bbfb-ab15923a4ef0.png)

## Status

```
version 1.0.1 — JUCE 8
```

This branch targets **JUCE 8**. The previous JUCE 7 codebase is preserved in
git history.

## Features

- VST3 plugin (Windows, macOS, Linux via JUCE exports)
- Built-in file browser tree to pick audio files
- Drag-and-drop audio files onto the waveform thumbnail
- Zoomable, scrollable waveform display with transport-follow mode
- Real-time-safe playback engine:
  - Audio readers are created on a background thread
  - Hot-swap of the active source via a lock-free FIFO
  - Reference-counted release pool to avoid deletes on the audio thread
- `Gain` and `Pan` parameters (equal-power panning law)
- `Play` parameter exposed for host automation
- Plugin state (current file path) persisted via `AudioProcessorValueTreeState`

## Requirements

- [JUCE 8](https://juce.com/) (modules folder available locally — see below)
- A C++17-capable toolchain
- One of:
  - **Windows**: Visual Studio 2022 (the `Builds/VisualStudio2026/` export is
    a placeholder; use `Builds/VisualStudio2022/` for the official build)
  - **macOS**: Xcode 14+ (export not generated yet — add via Projucer)
  - **Linux**: GCC/Clang + Makefile export from Projucer
- [Projucer](https://juce.com/discover/projucer) (ships with JUCE)

### Required JUCE modules

The `.jucer` declares the following modules. They must be reachable through the
configured `MODULEPATH` (or via the global JUCE path in Projucer settings):

```
juce_audio_basics          juce_audio_devices         juce_audio_formats
juce_audio_plugin_client   juce_audio_processors      juce_audio_utils
juce_core                  juce_cryptography          juce_data_structures
juce_events                juce_graphics              juce_gui_basics
juce_gui_extra             juce_audio_processors_headless
```

> `juce_cryptography` is required by the `MD5` hash used to identify non-local
> source URLs in plugin state. Missing this module is the most common build
> failure when porting from older forks.

## Building

1. Clone the repository:
   ```sh
   git clone https://github.com/filipeborato/tacapramim.git
   cd tacapramim
   ```
2. Make sure JUCE 8 is available locally. By default the `.jucer` looks for
   it at `C:\JUCE\modules` (VS2026 export) and at a relative path
   `../../../../../JUCE/modules` (VS2022 export). Adjust the module paths in
   Projucer if your layout differs, or set the JUCE global path under
   *Projucer → File → Global Paths…*
3. Open `tacapramim.jucer` in **Projucer** and click **Save Project** (this
   regenerates `JuceLibraryCode/` and the IDE projects under `Builds/`).
4. Open the generated solution / project for your IDE and build:
   - `Builds/VisualStudio2022/tacapramim.sln`
   - or the Xcode / Makefile export you generate
5. The VST3 is produced at the standard JUCE output location, e.g. on Windows:
   ```
   Builds/VisualStudio2022/x64/<Configuration>/VST3/tacapramim.vst3
   ```
6. Load it in your host (e.g. JUCE's *AudioPluginHost*) and pick an audio file
   in the tree to start playback.

## Migration notes — JUCE 7 → JUCE 8

If you are coming from an older checkout, note the following changes that were
required to compile cleanly under JUCE 8:

- **Added `juce_cryptography` module** to the `.jucer` (used by `juce::MD5`).
- **`juce::Font` constructor**: the `Font(float, int)` overload is deprecated
  in JUCE 8. Use `Font(FontOptions(height, style))` instead.
- **Stricter unused-parameter warnings**: stub overrides
  (`setCurrentProgram`, `getProgramName`, `changeProgramName`, `processBlock`'s
  `midiMessages`) now use `juce::ignoreUnused(...)` to silence warnings
  treated as errors.
- **`tacapramim.lib` not found** at link time on Windows is a *symptom*: it
  means the `SharedCode` target failed to compile. Fix the upstream compile
  errors and the linker error goes away.

After editing `.jucer`, always re-run Projucer's **Save Project** so
`JuceHeader.h` and the IDE projects are regenerated.

## Contributing

Issues and PRs are welcome. Please:

1. Branch from `master`.
2. Open `.jucer` in Projucer when adding/removing source files or modules
   (don't edit the generated `Builds/` files by hand).
3. Keep the audio thread real-time-safe (no allocations, locks, file I/O, or
   logging inside `processBlock`).
